# 🍳 今晚吃什么

> **墨墨背单词式做饭助手** —— 新菜 + 复习 + 自动采购，一站式解决「今天做啥、买啥、怎么做得更好」。

## 四大卖点

| # | 卖点 | 说明 |
|---|------|------|
| 1 | **AI 一周课程表** | 输入偏好与冰箱库存，DeepSeek 自动生成每周菜单，新课与复习穿插安排，告别「今晚吃什么」焦虑 |
| 2 | **墨墨式复习闭环** | 做过就忘？系统按掌握度（学习中 → 熟悉 → 拿手）智能排期，到期自动提醒复习，附带你的改进笔记一起进化 |
| 3 | **一键采购清单** | 菜单食材 − 冰箱库存 = 待购清单；同类合并、数量真加总、手动勾选已买，买完不被自动加回 |
| 4 | **分享卡片 & 进化笔记** | 小红书级 3:4 竖版 PNG 菜单卡片一键导出；每道菜的评分与改进要点持续积累，越做越拿手 |

### 核心动线

1. **偏好设置**（`/onboarding`）→ 已预填「2 人食、不辣、清淡」，直接进入主页
2. **一周课程表**（`/plan`）→ 5 新课 + 2 复习交替穿插，复习菜显示改进笔记（如宫保鸡丁显示「花生减半，辣度降一档」）
3. **⭐ 复习链路演示** → 重点看两道复习菜：**宫保鸡丁**（踩雷 1 星，带笔记，2 天间隔到期被系统召回）和**麻婆豆腐**（一般 2 星，7 天间隔到期）——这就是墨墨背单词式复习的核心：做过的菜不会消失，系统按掌握度自动排期，踩雷的菜更快被提醒再练
4. **菜谱详情 & 笔记回溯**（`/dish/[id]`）→ 点击宫保鸡丁进入详情，查看全部历史笔记 + 顶部「上次你说：花生减半，辣度降一档」横幅，点击「按改进要点重新生成做法」让 AI 按你的笔记修订菜谱
5. **吃菜回溯**（`/history`）→ 累计做过 10+ 道菜、拿手 3 道；每行显示掌握度徽章（学习中 / 熟悉 / 拿手），点击可跳转菜谱详情
6. **采购清单**（`/shopping`）→ 自动汇总：菜单食材 − 冰箱库存 = 待购清单，同类合并、数量真加总，可勾选已买或手动删除
7. **分享卡片** → 一键生成 3:4 竖版菜单 PNG（含新课/复习徽章与掌握度元素），可直接发小红书

> 演示模式幂等：无论浏览器是否有旧数据，均可随时进入。
