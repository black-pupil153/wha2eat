## 演示路径（`?demo=1`）

访问 `__PROD_URL__?demo=1` 进入预置演示态（幂等：无论本地是否有旧数据都会覆盖写入）。

### 六步动线

1. **打开演示** → 访问 `?demo=1`，自动写入偏好 / 冰箱 / 菜谱库 / 做饭历史，并进入一周课程表
2. **一周课程表**（`/plan`）→ 查看「新课 / 复习 / 应季」徽章；库内占槽体现节气优先于过季到期复习
3. **复习链路** → 点开到期复习菜（如带笔记「盐减半」的踩雷菜），详情顶栏显示「上次你说：…」
4. **按笔记进化** → 在菜谱详情点「按改进要点重新生成做法」，确认菜谱真的按笔记修订并写回菜谱库
5. **回溯 & 采购** → `/history` 看累计做过 / 拿手统计与掌握度徽章；`/shopping` 核对自动采购清单
6. **分享卡片** → 导出 3:4 竖版 PNG（含徽章与掌握度一行），可直接发小红书

> 演示重点：70% 看复习闭环（徽章 → 横幅「盐减半」 → 按笔记重生 → 菜谱变了）+ 应季优先占槽。
